Installation Guide

✓

Installation Complete

Follow these steps for a successful setup

1
2
3
4

Step 1: Download Files

Download the EveryM Menu files from our store and extract them to your server's resources folder.

Step 2: Configure Server

Edit your server.cfg file to include the following:

lua 
# EveryM Menu Configuration
start everym
set everym_menu_endpoint "https://your-server.com/api"
set everym_license "your-license-key"
ensure es_extended

Step 3: Database Setup

Import the provided SQL file into your database:

sql 
-- Import this file into your MySQL database
mysql -u username -p database_name < everym_menu.sql

Step 4: Restart Server

Restart your FiveM server to load EveryM Menu. The menu will be available to all administrators with proper permissions.

Important Notes:

  • Ensure es_extended is started before everym
  • MySQL connection is required for database features
  • Configure permissions in the config file
  • Test all features after installation

Configuration

Basic Configuration

Customize EveryM Menu behavior through the configuration file:

lua 
Config = {
    Locale = 'en',
    MenuKey = 'F2',
    AdminOnly = true,
    Permissions = {
        ['admin'] = true,
        ['moderator'] = false
    },
    UI = {
        Theme = 'dark',
        Position = 'top-left',
        Animation = true
    }
}

API Reference

everym:openMenu

Opens the EveryM menu interface for the player

lua 
-- Client-side
TriggerEvent('everym:openMenu')

exports['everym']:GetPlayerData()

Returns comprehensive player data object

lua 
-- Server-side
local playerData = exports['everym']:GetPlayerData(source)
print(playerData.identifier)

everym:playerAction

Triggered when a player performs an admin action

lua 
-- Server-side
RegisterNetEvent('everym:playerAction')
AddEventHandler('everym:playerAction', function(source, action, data)
    -- Handle player action
end)

Troubleshooting

Common Issues

⚠️

Menu Not Opening

Check if the menu key is configured correctly and that you have admin permissions.

✕

Database Connection Failed

Verify your MySQL credentials and ensure the database server is running.

Solutions:

  • Verify resource is started in server.cfg
  • Check console for error messages
  • Ensure all dependencies are installed
  • Validate license key
  • Contact support if issues persist
