Script Documentation

Overview

EveryM Menu is our flagship script featuring a modern, responsive interface with comprehensive server management tools.

✓ Modern responsive design
✓ Customizable themes and colors
✓ Advanced player management
✓ Real-time server statistics

Installation

Step 1: File Placement

resources/[everym]/

Place the entire 'everym' folder in your server's resources directory.

Step 2: Server Configuration

start everym

Add this line to your server.cfg file.

Step 3: Dependencies

ensure es_extended
ensure mysql-async

Make sure these dependencies are started before EveryM Menu.

Configuration

config.lua

Config = {
    MenuKey = 'F2',
    Theme = 'dark',
    Language = 'en',
    Permissions = {
        ['admin'] = true,
        ['moderator'] = true
    },
    Features = {
        PlayerManagement = true,
        VehicleSpawner = true,
        TeleportSystem = true
    }
}

API Reference

Client Events

everym:openMenu

Opens the EveryM menu interface

everym:closeMenu

Closes the menu interface

everym:notify

Shows notification to player

Server Events

everym:playerLoaded

Triggered when player data loads

everym:adminAction

Triggered on admin actions

everym:savePlayer

Saves player data to database

Export Functions

exports['everym']:GetPlayerData()

Returns player data object

exports['everym']:HasPermission()

Checks player permissions

exports['everym']:SendNotification()

Sends notification to player

Troubleshooting

Script Not Starting

Common Causes:

  • Incorrect resource name in server.cfg
  • Missing dependencies
  • File path errors

Solutions:

  • Verify resource name matches folder name
  • Ensure all dependencies are started first
  • Check console for specific error messages

Menu Not Opening

Common Causes:

  • Key binding conflicts
  • Permission issues
  • Resource not fully loaded

Solutions:

  • Change menu key in config
  • Verify player has required permissions
  • Wait for resource to fully initialize

Performance Issues

Common Causes:

  • Too many concurrent players
  • Resource conflicts
  • Database connection issues

Solutions:

  • Optimize server resources
  • Check for resource conflicts
  • Verify database connection settings
