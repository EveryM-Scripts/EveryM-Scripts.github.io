Prerequisites

Before installing EveryM scripts, ensure your server meets these requirements.

Server Requirements

  • FiveM Server Build 5849 or higher
  • MySQL 8.0+ or MariaDB 10.5+
  • Minimum 4GB RAM (8GB recommended)
  • Linux or Windows Server
  • Valid EveryM License Key

Required Frameworks

  • es_extended (latest version)
  • oxmysql or mysql-async
  • ox_inventory (for inventory features)
  • ox_target (for interaction system)

Basic Setup

Step 1: Download Scripts

Download your purchased scripts from the EveryM store. Extract the ZIP file to your server's resources folder.

bash 
# Extract to resources folder
cd /path/to/server/resources
unzip everym-scripts.zip

Step 2: Configure server.cfg

Add the following lines to your server.cfg file:

cfg 
# EveryM Scripts
start everym
start everym_menu
start everym_admin
start everym_vehicles

# Database Configuration
set mysql_connection_string "mysql://user:password@localhost/database"

# License Configuration
set everym_license "your-license-key-here"

Step 3: Database Setup

Import the provided SQL files into your database:

sql 
# Import SQL files
mysql -u username -p database_name < sql/everym_core.sql
mysql -u username -p database_name < sql/everym_menu.sql
mysql -u username -p database_name < sql/everym_vehicles.sql

Step 4: Start Server

Restart your FiveM server to load all scripts. Check the console for any errors.

Important Notes:

  • Always backup your database before installation
  • Start dependencies before EveryM scripts
  • Verify all file paths are correct
  • Test in a development environment first

Database Setup

MySQL Configuration

Configure your MySQL server for optimal performance with EveryM scripts:

sql 
-- Create database
CREATE DATABASE everym_server CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- Create user
CREATE USER 'everym'@'localhost' IDENTIFIED BY 'secure_password';
GRANT ALL PRIVILEGES ON everym_server.* TO 'everym'@'localhost';
FLUSH PRIVILEGES;

Database Tables

EveryM scripts will automatically create necessary tables on first startup:

  • everym_players - Player data and statistics
  • everym_vehicles - Vehicle information and customization
  • everym_admin_logs - Administrative action logs
  • everym_inventory - Player inventory data

Configuration

Main Configuration File

Edit the config/config.lua file to customize script behavior:

lua 
Config = {
    Framework = 'esx',
    Database = 'mysql',
    Locale = 'en',
    
    -- Menu Configuration
    Menu = {
        Key = 'F2',
        Position = 'top-left',
        Theme = 'dark',
        Animation = true
    },
    
    -- Admin Configuration
    Admin = {
        Permissions = {
            ['god'] = true,
            ['admin'] = true,
            ['moderator'] = false
        },
        Logging = true,
        Notifications = true
    },
    
    -- Vehicle Configuration
    Vehicles = {
        SpawnInside = true,
        MaxDistance = 100.0,
        SavePosition = true,
        CustomPlates = true
    }
}

Troubleshooting

Common Installation Issues

⚠️

Resource Not Starting

Check if all dependencies are properly installed and started before EveryM scripts.

✕

Database Connection Failed

Verify your database credentials and ensure MySQL server is running.

Solutions:

  • Check server console for error messages
  • Verify file permissions
  • Test database connection manually
  • Ensure correct resource order
  • Update to latest versions

Admin Tools Setup

Admin Configuration

Configure admin tools and permissions:

lua 
-- Admin tools configuration
AdminConfig = {
    Permissions = {
        ['kick'] = 'admin',
        ['ban'] = 'admin',
        ['teleport'] = 'moderator',
        ['spawn'] = 'admin'
    },
    
    Logging = {
        Enabled = true,
        Level = 'all',
        File = 'logs/admin.log'
    },
    
    Features = {
        Spectate = true,
        Teleport = true,
        VehicleControl = true,
        PlayerManagement = true
    }
}
